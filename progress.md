# kty Migration Progress

Tracks the ManimGL → web port. Task IDs mirror [`docs/04-migration-stages.md`](./docs/04-migration-stages.md).

**Status key:** ⬜ not started · 🟡 in progress · ✅ done · ⛔ blocked · ⏭️ skipped/deferred

**How to use:** when you pick up a task, set it 🟡 and put your name + date in Notes. When it merges, set ✅. Keep the per-stage summary line current. Don't delete tasks — mark ⏭️ with a reason.

_Last updated: 2026-06-10 (eve) — **3D Mesh render path shipped (S6.4)**: `Surface`/`ParametricSurface` sample a uv_func grid → `THREE.Mesh` (BufferGeometry + index + per-vertex normals, `MeshStandardMaterial`); `Sphere`/`Torus`/`Square3D`/`Cube`/`Prism`. The renderer now dispatches by `renderType` and adds lights only when a surface is present (2D stays unlit/unchanged). `CameraFrame` gained perspective: `fovy` + zxz Euler orientation (`reorient`), with `Camera` picking Orthographic for flat framing and Perspective once tilted into 3D. `applyPointsFunction` now transforms all `pointlikeDataKeys` so surface normals survive transforms. 228 unit tests; sphere/torus/cube pixel-diffed in CI. Next: S6.5 point-cloud (THREE.Points) + image (texture) paths reusing this dispatch._

_Prior (2026-06-10 pm) — **Formal visual-regression gate shipped** (the 🔴 Stage 3 GATE): Playwright + pixel-diff in CI, goldens generated byte-reproducibly in the pinned `mcr.microsoft.com/playwright:v1.49.1-jammy` container (`tests/visual/`, `.github/workflows/visual.yml`). It immediately caught two real Tex/Text bugs, both fixed: (1) MathJax glyphs rendered **upside down** (y-down vs y-up) → seed glyph walk with a y-flip; (2) glyph **counters filled solid** (`o`/`0`/`e`/`a`/`g`) → nest inner contours as `THREE.Shape` holes by containment. **Released to public npm as `@viesar/kty@0.1.2`**, consumed by the live docs site (test.kty.victorarce.com). 204 unit tests green. The per-stage "formal PNG-diff pending" caveats (S3.8/S3.10/S4.4/S5.10/S6.7/S7.8) are now satisfied by this gate. Next: 3D / Mesh / point-cloud renderer paths (S6.4–6.6)._

_Prior (2026-06-10 am): Text/numbers layer finished on the Tex pipeline — DecimalNumber/Integer, Text, axis tick labels, number animations. Deferred: opentype system-font Text, Matrix, string color-maps, boolean ops, braces, TransformMatching._
